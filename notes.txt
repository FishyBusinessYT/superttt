The game state:

    xmarks: An array of 9-bit numbers representing all of X's marks on every board.
    omarks: Same thing but for O.
    xwon: A 9-bit integer representing all of the boards where X has already won.
    owon: Same thing but for O.
    isXsTurn: Keeps track of who's to place their mark next. Toggled whenever a
     mark is placed or removed. X goes first, so its initial value is True.
    lastPickedCell: Which of the 9 cells was picked last. May influence the next
     turn's options. Remove later.
    moveHistory: Keeps track of all the moves that have been made until this
     point. Useful for undo and search algorithms later on.

    checkBoards: This function updates xwon and owon according to the marks
     placed by either player. Should also check which player's won.
    getBoardOwner: This function checks  either 1, 2, or nil.

    The system is designed so that omarks[i] & xmarks[i] always equals 0. That
    is, no board (i) can have a mark (m) for both players at the same time.

    Viualization of a board:

    +-----+-----+-----+
    |     |     |     |     omarks = 0b110100010
    |  X  |  O  |  X  |
    |     |     |     |     omarks = 0d418
    +-----+-----+-----+
    |     |     |     |     xmarks = 0b000010101
    |     |  X  |  O  |
    |     |     |     |     xmarks = 0d21
    +-----+-----+-----+
    |     |     |     |
    |     |  O  |  O  |     bit index: 987654321
    |     |     |     |
    +-----+-----+-----+


A move:

    A move is a tuple containing two integer numbers from 1-9, one for the board
     and another for the cell. It can pretty much be interpreted as a set of 
     coordinates where x=board and y=cell.

    move[1]: The board
    move[2]: The cell
